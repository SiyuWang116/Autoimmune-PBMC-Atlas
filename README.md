# Autoimmune PBMC Atlas

Analysis code for a cross-disease single-cell atlas of peripheral immune cells across autoimmune diseases.

## Overview

This study integrates publicly available single-cell RNA-sequencing datasets to characterize immune cell heterogeneity, disease-associated cell populations, and shared peripheral immune modules.

## Analyses

- Data preprocessing, integration, and cell annotation
- Comparison of immune cell composition across diseases
- Characterization of rare naïve B-cell subsets and BCR repertoires
- Analysis of Treg composition and functional signatures
- Characterization of C1QC-positive monocytes
- Identification of shared immune modules using non-negative matrix factorization (NMF)
- Validation using independent single-cell and bulk transcriptomic datasets

## Data availability

Dataset accession numbers and sources are provided in Supplementary Table 1 of the accompanying manuscript. Additional bulk transcriptomic datasets include GSE64486 and GSE68004.

## Usage

Scripts should be run with the corresponding input datasets. File paths must be updated to match the local environment. Software dependencies and the recommended execution order will be documented alongside the scripts.
